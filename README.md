# Java Practice Programs

A collection of core Java programs covering number system conversion, array manipulation, 
searching/sorting logic, and basic operating system scheduling concepts. Built as part of 
an assignment to practice fundamental data structures, algorithms, and problem-solving in Java.

## Programs

| # | Program | File | Concept Covered |
|---|---------|------|------------------|
| 1 | Octal to Binary and Binary to Octal Converter | `OctalBinaryConverter.java` | Number system conversion, arrays, string manipulation |
| 2 | Remove Duplicates from an Array | `RemoveDuplicates.java` | HashSet, two-pointer technique |
| 3 | Longest Increasing Subsequence | `LongestIncreasingSubsequence.java` | Dynamic Programming (DP) |
| 4 | FCFS Job Scheduling | `FCFSScheduling.java` | Operating Systems, CPU scheduling algorithms |
| 5 | Check if Array is Sorted | `CheckSortedArray.java` | Array traversal, conditional logic |
| 6 | Merge Two Sorted Arrays | `MergeSortedArrays.java` | Two-pointer technique, merge logic (Merge Sort foundation) |

## How to Run

Each file is a standalone Java program. To compile and run any program:

```bash
javac ProgramName.java
java ProgramName
```

- Java (JDK 17+)
